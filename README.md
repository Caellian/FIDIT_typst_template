# FIDIT Typst Template

[Template](https://typst.app/docs/tutorial/making-a-template/) za typst koji
definira stil dokumenta prema smjernicama fakulteta za završni rad.

Template podržava izradu različitih vrsta dokumenta:
- Seminarski rad
- Završni rad
- Diplomski rad
